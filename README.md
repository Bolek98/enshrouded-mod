# Enshrouded mods by Bolek98 [B98]

Mods for **Enshrouded** (EML / ShroudForge, Lua) and the **Enshrouded Mod Manager**.

| Mod | Folder | What it does |
|---|---|---|
| [B98] More XP & skill points | `mods/b98-xp` | XP multiplier (combat, mining, exploring, quests), more skill points per level, no group XP penalty |
| [B98] Extended world settings | `mods/b98-world` | World-setting sliders go much further: day and night length, plant growth, crafting, mining, resources, XP, player / enemy / boss strength, time in the Shroud, food |

## Install
Copy the mod folder into `Enshrouded\mods\` (needs the EML / ShroudForge mod loader) and enable it in the loader's in-game menu.
Settings: `src/config.lua`, or in the Enshrouded Mod Manager (`manager.json` describes the settings for it).

# Mody do Enshrouded od Bolek98 [B98]

Mody pro **Enshrouded** (EML / ShroudForge, Lua) a **Enshrouded Mod Manager**.

| Mod | Složka | Co dělá |
|---|---|---|
| [B98] Víc XP a skill pointů | `mods/b98-xp` | Násobič zkušeností (boj, těžba, průzkum, questy), víc skill pointů za level, XP ve skupině bez postihu |
| [B98] Rozšířené nastavení světa | `mods/b98-world` | Posuvníky v Nastavení světa jdou mnohem dál: délka dne a noci, růst rostlin, výroba, těžba, suroviny, XP, síla hráče, nepřátel a bossů, čas v Závoji, jídlo |

## Instalace
Zkopíruj složku modu do `Enshrouded\mods\` (potřebuje zavaděč EML / ShroudForge) a zapni ho v jeho menu ve hře.
Nastavení: `src/config.lua`, nebo v Enshrouded Mod Manageru (`manager.json` popisuje jeho nastavení).
